Shorts Factory

A personal desktop tool for managing my own YouTube channels.

Shorts Factory is a private Windows application used only by its developer to edit and manage the YouTube Shorts of the developer's own channels. It is not offered, sold or distributed to anyone else.

It uses YouTube API Services to:

  • read the analytics of the developer's own channels (views, retention, likes), to learn which video formats work best;
  • upload and schedule videos to the developer's own channels.
